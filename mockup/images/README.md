# images/

Esta carpeta se dejó preparada en la estructura del mockup, pero no contiene archivos binarios: los avatares de clientas/personal se generan en tiempo real con CSS/JS a partir de las iniciales del nombre (ver `js/utils.js → avatarHTML`), y las imágenes referenciadas dentro de las conversaciones de chat (ej. fotos de referencia de uñas) se simulan con un bloque de color, no con archivos reales — evita depender de binarios externos para que el mockup siga siendo 100% autocontenido y liviano.
